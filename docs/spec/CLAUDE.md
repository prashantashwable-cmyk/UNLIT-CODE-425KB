# Working inside docs/spec
- Spec files are reference text. Open one only when the task cites it. Prefer `python3 scripts/spec.py ...` or `rg`.
- Requirements, tests, screens, stages, permissions, decisions are already structured in `docs/data/`. Do not re-parse markdown tables.
- Do not edit requirement text. Propose changes in `docs/adr/` or ask the owner.
